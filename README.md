# Acumetis Waste Management – Embedded Earth

This version embeds the Earth photo directly inside `index.html`.

Upload only these files to the root of the GitHub repository:

- index.html
- styles.css
- app.js
- README.md

There is no separate Earth image file and no assets folder.

After uploading:
1. Replace the existing files.
2. Commit the changes.
3. Wait for GitHub Pages to redeploy.
4. Hard-refresh the live page with Ctrl + Shift + R.
